# MonthRibbon

Shows the next 12 months of large, known costs and whether each one's bucket will cover it.

- **Cells:** one per month, in data type. The current month is marked with accent-soft.
- **Status:** "Funded" on accent-soft, or "Short [amount]" on a cell filled attention-soft. Always written in words.
- **Wider than the screen:** the ribbon scrolls sideways inside its own box; it never shrinks the text.
- **Selecting a cost** opens its job in Plan. Every date and amount was set or confirmed by the family.
