# NavItem

A sidebar entry: the screen's name, an optional badge, and its single-letter shortcut in a key chip.

- **Active item:** surface-raised fill, text colour, 600 weight; its key chip gets an accent border.
- **Badges are facts, not alarms:** "Import due", "3 need you". They use attention-soft only when the family needs to act.
- **Key chips:** use the data font so the letters line up. Keys follow the interface language and can be turned off in Settings.
- **Size:** at least target-min tall; the whole row is the link.
