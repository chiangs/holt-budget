# TickScale

Shows one value against the targets and limits the family set: the house style for vital signs, buffer progress and a job against its plan.

- **Parts:**
  - a ticked scale (chart-grid ticks over chart-track)
  - the value bar (chart-1, scale-height, radius-xs)
  - one or two reference marks (chart-ref; a secondary threshold in text-muted)
  - the value in figure-xl
  - a data-caption naming each reference and where it came from ("your setting")
- **Scale:** choose a range that puts the main reference at roughly two thirds to four fifths of the width. Ticks at even, round steps.
- **Never** a ring, gauge or donut. When the value passes a limit, the bar stays chart-1 and the caption says so in words ("over your 5× limit"). The row gets an attention-soft background only if the family needs to act.
- **Selecting it** opens the working: the formula, the figures and their sources.
