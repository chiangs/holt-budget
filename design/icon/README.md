# Holt app icon: the grove

Dark green plate (#1f5446), orange ground line (#e09a73). Trunk colours #f3f1ee, #c0cfcb, #84a199.

| File | Use |
|---|---|
| `holt.svg` | Main master, 48 px and up (also `scalable`) |
| `holt-small.svg` | Drawn on a 16 px grid: use at 16 and 32 px |
| `holt-24.svg` | Drawn on a 24 px grid: use at 24 px |
| `holt-symbolic.svg` | One colour, no plate: tray, bar, notifications |
| `png/holt-<size>.png` | Pre-rendered from the matching master |

Suggested install paths (freedesktop hicolor theme; the final app ID is still to be decided):

```
share/icons/hicolor/scalable/apps/holt.svg              <- holt.svg
share/icons/hicolor/<N>x<N>/apps/holt.png               <- png/holt-<N>.png  (16 24 32 48 64 128 256 512)
share/icons/hicolor/symbolic/apps/holt-symbolic.svg     <- holt-symbolic.svg
```
